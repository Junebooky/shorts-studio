# Local readiness and integration
Run `npm ci` then `npm run doctor` from the repository. Use `node scripts/doctor.mjs --json` for machine-readable checks. Node 22+, npm, the main dependencies and local FFprobe on PATH are required for the full local workflow. FFmpeg and Python are optional for local conversion/Whisper; upstream skill checkout optional. The report checks only module resolution, local executable exit status, configuration presence (not expanded or authenticated), and skill directory presence. It makes no network or paid requests, prints no secrets, and does not test Chromium or Antigravity execution. Missing required items exit 1. FFprobe validates actual media duration on A03 asset registration/save/review and backup/restore; legacy discrepancies may require re-registering media. The joint integration workflow generates a synthetic WAV/MP4/reference, deliberately supplies false client durations, saves, exports/restores, verifies bytes, timing, placements and approval reset, and renders restored content with technical QA. Synthetic tone is not actual speech, no subjective approval. No user data is uploaded.
