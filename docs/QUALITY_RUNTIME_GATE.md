# QuickCreate P0 runtime gate
This main-based priority subset ports the already-verified final decode, atomic publication and exclusive output lock from frozen A02 #9 into the runtime used by QuickCreate. No shared API/App/quick-create/production changes. Before a full-size MP4 is published, render() verifies technical metadata, decodes the streams via bundled ffprobe -count_frames, requires exact expected video frames, and binds byte length/SHA; failure leaves previous output unchanged. QuickCreate independently calls inspectQuality(final) before done; decoder unavailable or mismatched count blocks success. Preview still rendering remains unchanged. This incurs two decoded scans for QuickCreate. Report integrity is optional for legacy reports; no subjective approval or download-time revalidation. Existing render() optional signal is not wired into shared jobs. Recovery CLI requires explicit offline confirmation. The independent browser fixture uses synthetic providers; no real narration or live paid calls.
