# Motion style selection
Six fixed presets + AI auto. Gallery thumbnails and silent 6s samples use the real Short composition. A selected preset is stored on project.styleId, copied to new project/duplicate, enforced in storyboard compiler, and resolved by the renderer independent of any agent theme. Palette, layout, typography, motion entrance duration and stagger, stroke weights and background change. Existing audio/captions/scene times are preserved when switching styles. Semantic re-direction may still require the single agent to replan; fixed preset is not a universal automatic art director. Data mode uses concept diagrams unless factual numbers are provided. AI auto leaves palette and direction flexible. User-approved fixed style overrides agent theme. Draft styleGuide is a helper; remove before applying, keep styleId. For a locked preset, color controls are disabled; switch to AI auto to customize. UI styling remains independent of video styling. Render comparisons: npx tsx scripts/render-styles.ts (six 540x960 silent clips plus 1080x1920 stills). Production export remains full resolution.
