# Motion style selection
Six fixed presets + AI auto. Gallery thumbnails and silent 6s samples use the real Short composition. A selected preset is stored on project.styleId, copied to new project/duplicate, enforced in storyboard compiler, and resolved by the renderer independent of any agent theme. Palette, layout, typography, motion entrance duration and stagger, stroke weights and background change. Existing audio/captions/scene times are preserved when switching styles. Semantic re-direction may still require the single agent to replan; fixed preset is not a universal automatic art director. Data mode uses concept diagrams unless factual numbers are provided. AI auto leaves palette and direction flexible. User-approved fixed style overrides agent theme. Draft styleGuide is a helper; remove before applying, keep styleId. For a locked preset, color controls are disabled; switch to AI auto to customize. UI styling remains independent of video styling. Render comparisons: npx tsx scripts/render-styles.ts (six 540x960 silent clips plus 1080x1920 stills). Production export remains full resolution.

The path visual now uses style-specific shapes and route geometry: labeled data boxes, kinetic diamond markers, soft illustrated nodes, cinematic halo, and minimal outlined dots. Demo style browsing is temporary; duplicate the demo to render a selected preset. Gallery is disabled during render and changing styles clears the old job link to avoid downloading a stale style. Samples intentionally contain the same semantic content for comparison.

## Fixed style contract and comparison
The existing six preset IDs, exact palettes and renderer values are unchanged. `styleContract` exposes the actual layout, headline baseline, entrance/stagger frame counts and stroke scale plus a semantic planning rule. `styleInstruction` includes these in the existing storyboard guide without adding schema fields; rules are guidance, not semantic QA or new rendering effects. Effective palettes are defensive copies. The gallery displays the locked palette and rules and provides read-only two-style comparisons at the same first/closing sample frames. No comparison click changes the saved style; use the existing selection cards for that. With AI auto, comparisons use two fixed sample presets and are not an AI-generated preview. Render CI on relevant PRs produces six silent videos and twelve stills (first and closing scenes) with a contract manifest. Automated renders do not constitute visual approval.
