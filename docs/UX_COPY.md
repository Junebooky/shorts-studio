# Shorts Studio UX copy guide

- 메뉴와 버튼은 짧게, 행동을 명확하게: 저장, 요청 복사하기, 영상 만들기.
- 안내와 오류는 자연스러운 해요체. 무슨 일이 생겼는지, 다음 행동이 무엇인지 알려준다.
- 사용자에게 익숙한 용어: 제작 과정, 제작 방향, 참고 자료, 작업 버전. 스토리보드, 타임라인, MP4는 유지한다.
- 실제 기능을 과장하지 않는다. 제작 요청 준비는 자동 AI 실행이 아니다. 기술 검사와 실제 시각·청취 검수는 구분한다.
- 외부 서비스 전송, 크레딧 사용, 기존 데이터 초기화 및 취소 제한은 삭제하거나 약화하지 않는다.
- 문구 변경 시 접근성 이름과 브라우저 테스트의 selector를 함께 확인한다. 데이터 키와 내부 상태, 에이전트 명령, 렌더링 로직은 변경하지 않는다.
