# Source to Threads (P1)
ThreadStudio is a real local editor, available through initial selection, direct workspace and the common-source conversion action even for a video-only plan. If a plan has no narration, open an explicitly labeled blank draft with topic as name; do not invent content. If a manual or video source exists, reuse its exact title and narration, split by sentence/word boundaries where possible (target 260 UTF-16 units), title prefixes first post. No new facts, hashtags, CTA, AI rewriting or paid provider calls. Video provenance records project ID and revision; manual and topic origins record plan ID. A saved source-linked draft is reopened without regeneration; a separate explicit conversion action replaces the draft only after confirmation. Original source is unchanged. One local thread draft with stale/corrupt/quota guards; incomplete drafts can be saved; copy/export requires nonblank valid posts. Each post can be edited, moved, deleted, copied; add up to 20. Standard plain-text posts use a conservative 500 UTF-16 unit limit (not an exact emulation of Meta's Unicode counting). Meta reference: https://about.fb.com/news/2025/09/attach-text-threads-posts-share-longer-perspectives/ (long-text attachments are separate, not supported here). TXT export separates posts with ---; individual copy preserves content. No connected accounts, posting, scheduler, cloud sync or actual platform acceptance verification. Brand tone is preserved through original narration rather than AI rewriting; no invented voice/persona. Next: unified result/review hub, then shared brand engine.
