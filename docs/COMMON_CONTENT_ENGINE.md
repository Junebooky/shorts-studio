# Common content source engine (P0)
One idea, one source, one brand, multiple formats. Current implementation persists **one active plan** and a versioned source snapshot in this browser (not a cloud account or multi-plan library). Plans include selected formats, topic, and saved brand snapshot. A non-default saved brand with sufficient contrast preselects its 3-color video palette; the user can change it in step 2. Unreadable brand colors do not lock the video palette. Optional user-authored Korean narration is validated using the same contract as the AI-generated script; QuickInput.sourceScript bypasses the script model call, but voice, storyboard, render and quality checks remain unchanged and require consent. No model is called when merely planning. A successful quick job attached to a matching launch/plan/topic captures the actual saved project ID/revision, exact title/script, brief, effective 3-color palette, duration, caption evidence and scene data. A failed job, different topic or subsequent generation cannot replace an already captured video source. Captured scene metadata may include asset references, not copied media. Source snapshot is not an approval or final output. Manual narration cannot be silently rewritten by capture. Browser storage rejects stale or invalid snapshots and quota failures; replacement of an existing source requires confirmation. Saved project files remain separate.
Card studio opens an explicitly confirmed new draft using shared title and brand snapshot; when source is a completed video draft, map its background/foreground/accent to card background/foreground/both accent roles, preserving saved brand font/logo/tone. Existing open card draft stays intact; source panel exposes exact narration and explicit color application. Scene-to-card page generation and static graphics are now implemented (see VIDEO_TO_CARD.md); source-grounded Threads draft generation is also implemented (see SOURCE_TO_THREADS.md); cloud synchronization, external publishing and multi-format final QA remain pending. Reopen saved source video after refresh by actual project ID; this opens latest saved project, not historical source revision. Source snapshot itself remains pinned. Current browser store is local only and replacement of the single active plan is explicit.
