# Common content source engine (P0)
One idea, one source, one brand, multiple formats. Current implementation persists **one active plan** and a versioned source snapshot in this browser (not a cloud account or multi-plan library). Plans include selected formats, topic, and saved brand snapshot. Optional user-authored Korean narration is validated using the same contract as the AI-generated script; QuickInput.sourceScript bypasses the script model call, but voice, storyboard, render and quality checks remain unchanged and require consent. No model is called when merely planning. A successful quick job attached to a matching launch/plan/topic captures the actual saved project ID/revision, exact title/script, brief, effective 3-color palette, duration, caption evidence and scene data. A failed job or different topic does not replace the source. Captured scene metadata may include asset references, not copied media. Source snapshot is not an approval or final output. Manual narration cannot be silently rewritten by capture. Browser storage rejects stale or invalid snapshots and quota failures; replacement of an existing source requires confirmation. Saved project files remain separate.
Card studio opens an explicitly confirmed new draft using shared title and brand snapshot; when source is a completed video draft, map its background/foreground/accent to card background/foreground/both accent roles, preserving saved brand font/logo/tone. Existing open card draft stays intact; source panel exposes exact narration and explicit color application. No automatic page generation, motion graphic still rendering, thread generation, cloud synchronization, external publishing or multi-format final QA yet. Reopen saved source video after refresh by actual project ID; this opens latest saved project, not historical source revision. Source snapshot itself remains pinned. Current browser store is local only and replacement of the single active plan is explicit.
## Design roadmap (updated)
1. Video workspace focus and progressive disclosure — main (#58).
2. Brand color-only creation/recolor, spacing, button visibility — main (#60).
3. Multi-format initial selection and handoff — main (#59).
4. Common content source engine — this change: shared narration contract, captured source, persistence, reuse, brand mapping. CI and merge required.
5. Shorts to card news — next: derive pages from source scenes/captions, preserve semantic diagrams and adapt to 4:5, per-page text/layout verification; don't just capture arbitrary video frames.
6. Shorts to Threads — source-grounded editable post sequence and platform length validation; no automatic publishing.
7. Unified completion — real per-format results, download/review, offer unselected derivatives, no fake completion.
8. Shared brand management — unify 3-/4-color contract, versioned variants and accessible palette across formats, without overriding semantic colors.
9. Research, publishing, analytics — later, after verified creation workflow.
