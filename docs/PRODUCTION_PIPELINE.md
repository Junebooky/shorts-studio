# Production-first delivery
Priority: complete reliable script → voice → timing → style → agent request → authored storyboard → actual render/review → revision → final MP4 before adding camera/morph/individual effect enhancements. Keep current six styles and shadow-first UI. Production dashboard shows evidence-derived readiness, not fake agent progress. New project: save script, select style, generate or upload voice, import timing. Listen to actual voice and record review; request file in workspace/projects/ID/production/request.json includes timing evidence and style instruction. Copy to single Antigravity agent (no direct invocation). Agent uses existing storyboard draft/apply, actual semantic graphics, verifies transcript and claims, then renders review. Web or CLI: npx tsx scripts/production.ts status|voice|request|review|approve|final ID [review notes]. Agent only records voice/visual approval after actually listening/inspecting, never just because tests pass. If unable to listen/watch, leave unapproved or ask human. Review generates 540x960 proxy and full-size sampled stills in out/ID/review/rREV/frames; inspect all representative frames and full playback. Record problems, edit project/engine, regenerate review; approval becomes invalid after revision/engine/audio change. Final gate applies to production final route; legacy draft MP4 remains available for iteration, not release certification. Production output is not an objective quality guarantee; final acceptance requires user review. No paid API calls by CI. Remaining priorities: real ElevenLabs Korean voice, autonomous agent handoff and status, assets/reference inputs, robust visual/audio QA and issue/revision cycle, repeated real content. Do not prioritize camera effects until these work end-to-end.

Review records bind the actual proxy and PNG bytes plus a unique render run ID. Changed, missing, or replaced evidence invalidates approval, and every new review requires a new approval. Final render rechecks the gate after rendering. CI exercises the full path on the explicitly synthetic fixture; test-only approval records do not signify human or agent visual/listening review.

Task-specific immutable request, local milestone log and revision feedback: docs/AGENT_BRIDGE.md.
