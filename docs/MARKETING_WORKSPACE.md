## Brand Kit
Functional route 콘텐츠 라이브러리 > 브랜드 키트. Single workspace-level kit saved in browser localStorage: name, optional raster logo (PNG/JPEG/WebP max 256KB, browser decode and dimensions <=4096), four hex colors, font family, design style, tone, guidelines. Draft remains in shell state when switching modules; explicit save; validated versioned storage, corrupt data protection and pre-write other-tab check. Preview supports video, carousel and thread layouts with live settings; no external calls or rendering. Text/background contrast checked against 4.5:1 for ordinary text (not full accessibility certification); chosen primary pill ink based on contrast. Font families are previews, not custom font upload or guaranteed output fonts. Actual production integration, multi-brand profiles, server persistence, campaign binding and common asset library remain future work; no changes to existing App or rendering. Tests cover validation, persistence, logo upload and format preview, reload. Existing video remains default.
