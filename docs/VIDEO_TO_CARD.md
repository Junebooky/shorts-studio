# Video to card news (P1)
Convert an existing common video snapshot, not a random MP4 frame. Cover uses source title; each scene maps to one or more body pages, with captions assigned once by midpoint and long copy split at safe boundaries. All source graphics are retained as VisualSchema data and original layout; semantic and editorial SVG components share the video renderer geometry and fully revealed state. Semantic material colors stay independent of brand colors. Canvas renders static SVG geometry and paints labels with loaded document fonts; page text, SVG label bounds and existing overflow checks gate PNG export. 1080x1350 default; 1080x1080 supported. No new provider calls. Media references are not copied: external photos/videos are explicitly omitted; scenes without visuals remain text pages. This is a draft, not visual approval. Existing manual cards remain valid. More than 20 pages is rejected with a clear message, no silent loss. User confirms replacement; save is separate; original video and existing saved card remain untouched before save. Persisted provenance prevents re-opening the same source deck from replacing edits after reload. Explicit conversion is also available on the common source panel for video-only plans. Current limit one local saved deck, no batch export or external MP4 ingestion. Next: Threads, unified result/review hub, shared brand management.
