# Storyboard contract
Save a project with current Master Timeline, then run npx tsx scripts/storyboard.ts draft PROJECT_ID.
The draft contains caption evidence and empty creative fields; it is NOT a usable board. The single Antigravity agent must write a new JSON file conforming to src/core/storyboard.ts StoryboardSchema. Remove captionEvidence/timingIssues helper fields. Group consecutive caption IDs by meaning; each ID occurs exactly once, original order. No timestamps are entered by the agent. Set direction (concept, audience, style, author), theme, per-beat headline, purpose, metaphor, kicker, detail, and visual. Visual types: path (3 labels), contrast (left/right), cycle (3 labels), focus (word), typography (2 lines). Implement new visuals as needed rather than forcing templates. No fictional quantities, logos, data or claims.
Apply: npx tsx scripts/storyboard.ts apply PROJECT_ID FILE. Or import the JSON in a saved project in the UI. Stale revision or missing timing review acknowledgement rejects the board. Review acknowledgement is not proof of acoustic accuracy. Original narration and captions are preserved. Actual frame and full playback review remain mandatory.

## Speech-driven motion cues
Optional beat.cues: [{"slot":0,"wordIndex":14,"expectedWord":"변화"}]. Index is from draft.wordEvidence; never invent timestamps. Slots 0–2 for path/cycle, 0–1 contrast/typography, 0 focus. Order by slot, verify semantic correspondence and that word lies in scene. Compiler resolves exact absolute times and renderer begins element reveal at corresponding frame; absent cues use standard stagger (not claimed speech-synced). Base path/circle framing can appear before the specific word; label/target reveal is timed. Remove wordEvidence helper field from final board. Low-confidence words rejected. No word evidence in SRT-only source means no automatic word-level cues.

User style selection: preserve draft.styleId (auto for legacy), read draft.styleGuide then remove helper styleGuide before applying. Fixed preset palette and direction label override board theme/style; conflicting style ID is rejected. Select graphics and semantic metaphors appropriate to the style, not just colors. See docs/MOTION_STYLES.md.

Asset usage and reference brief: docs/ASSETS.md. Only production assets can be placed in a scene or music; reference assets are for actual agent inspection. Remove draft assetEvidence/referenceBrief helper fields before applying.
