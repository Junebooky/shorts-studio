# Storyboard contract
Save a project with current Master Timeline, then run npx tsx scripts/storyboard.ts draft PROJECT_ID.
The draft contains caption evidence and empty creative fields; it is NOT a usable board. The single Antigravity agent must write a new JSON file conforming to src/core/storyboard.ts StoryboardSchema. Remove captionEvidence/timingIssues helper fields. Group consecutive caption IDs by meaning; each ID occurs exactly once, original order. No timestamps are entered by the agent. Set direction (concept, audience, style, author), theme, per-beat headline, purpose, metaphor, kicker, detail, and visual. Visual types: path (3 labels), contrast (left/right), cycle (3 labels), focus (word), typography (2 lines). Implement new visuals as needed rather than forcing templates. No fictional quantities, logos, data or claims.
Apply: npx tsx scripts/storyboard.ts apply PROJECT_ID FILE. Or import the JSON in a saved project in the UI. Stale revision or missing timing review acknowledgement rejects the board. Review acknowledgement is not proof of acoustic accuracy. Original narration and captions are preserved. Actual frame and full playback review remain mandatory.
