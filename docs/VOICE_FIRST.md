# Voice-first production
TTS with timestamps: https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps
Forced alignment: https://elevenlabs.io/docs/api-reference/forced-alignment/create
Choose a Korean-native voice from your account. Default Multilingual v2 (stable baseline); v3/v4 options experimental until live tested with timestamps. Generate complete narration in one request for continuity, no automatic paid retries. PCM 24kHz requested and wrapped losslessly in WAV; duration from samples, not last timestamp. Original alignment required; if absent/mismatched, preserve generated audio and mark unverified, then request forced alignment explicitly. Forced-alignment loss is stored in raw evidence; matching text is not proof of acoustic accuracy. User approves external transfer/cost through UI. No private key in browser, public repo or CI; set .env.local. Never use eSpeak as production narrator. Listen and approve voice before storyboard. Existing audio may be uploaded and aligned, Whisper is offline fallback. Do not regenerate accepted narration automatically. Local network DNS unavailable in authoring environment, live requests not verified. Tests mock provider only.

## P0 response integrity
Malformed or missing original alignment does not discard valid generated PCM: save the audio as unverified, clear captions/scenes, and require explicitly approved forced alignment. Reject invalid/non-canonical base64 and invalid PCM before upload; reject raw overlapping/reversed timing even when rounding to milliseconds would hide it. Matching caption text alone cannot certify contradictory word anchors; ElevenLabs evidence without word anchors requires review. HTTP/JSON errors are sanitized and never retried automatically. No live provider validation is implied by mock tests.

## Voice review UI
Local configuration status distinguishes missing key, loading and connection error; retry checks only the local status endpoint. Paid generation/alignment still requires explicit consent, and duplicate clicks are locked while requests are active. Timing review exposes source, segment/word timestamps and reported confidence; SRT without word evidence never implies word alignment. Waveform peaks cover all decoded samples/channels; file/project duration differences over 100 ms are flagged, and the keyboard range selects a seek target (not a live playhead). The 100 ms display warning is a heuristic, not a production gate. Real provider and acoustic QA remain separate.

## Topic-to-video voice handoff (P0 priority)
The quick path should invoke `generateNarration` exactly once per explicit user attempt, then use the persisted audio and matched Master Timeline for storyboard compilation. A malformed original alignment, even with a normalized alignment, leaves the paid PCM saved as unverified; do not silently substitute it, invent timings or retry TTS. Surface the new project's ID and offer explicit alignment of the existing audio. The recovery may itself incur a provider charge and requires explicit user consent. A rate-limited or otherwise failed provider request leaves the script-only project intact. Concurrent requests on the same project are rejected by the voice lock; an intervening save causes the stale response's revision check to reject the project write (uploaded bytes/evidence may remain orphaned; no automatic cleanup or global cross-process lock).
The dedicated mock CI includes a 45-second synthetic PCM fixture with a Korean script, source-byte equality, a real storyboard compile with frozen style/brief/captions, explicit forced-alignment recovery, concurrent/stale response protection and 429 behavior. These exercise the same voice functions used by the quick-create path without importing or modifying A01's orchestration. No live provider, browser UI, actual MP4 render or natural speech quality is claimed by these tests. A01 owns end-to-end topic-to-video browser/render validation.

## Quick path failure regression on merged orchestration
The generator rejects exactly all-zero PCM before uploading or marking the timeline verified; no arbitrary loudness threshold and no automatic retry. This is a digital silence guard, not acoustic or speech-quality analysis. The paid request may already have incurred cost. New actual `runQuick` mock tests verify silent output leaves a script-only project; missing alignment stops before storyboard/render, then explicit alignment of the original WAV and normal compiler reuse those exact bytes; invalid storyboard preserves matched voice. No automatic resume UI, paid provider calls or actual render in these tests. A01 owns resume orchestration and UI; do not generate another voice automatically.
