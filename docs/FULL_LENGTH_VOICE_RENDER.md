# Full-length synthetic Korean quick creation fixture
P0 follow-up to #31/#36, separate from guided creation and real provider calls. Generates isolated Korean words with eSpeak NG, resamples to 24 kHz mono PCM, trims low-level edges and inserts measured gaps. Target 35–60 s; never stretches audio. Word boundaries come from sample counts, within-word character subdivisions are synthetic mock transport only, not measured character alignment. The Korean narration is deliberately non-natural isolated words; no live ElevenLabs, real ASR, Gemini/OpenAI API or human listening claim.
The actual merged runQuick implementation is exercised with an intercepted text/voice/board response, fixed synthetic semiconductor topic, six grouped scenes and five existing visual types. No shared source or engine changes. Verify original PCM equality, all word boundaries after rounding, complete timeline, 1080x1920 30fps MP4 via actual renderer and technical gate, independent full decode, audible stream level, and no automatic approvals. The test does not validate semantic accuracy, visual quality or naturalness. Fixture output is synthetic and may be downloaded from CI artifacts only after successful creation.
Run python3 scripts/full-length-voice-fixture.py and npx tsx scripts/full-length-quick-render.ts with eSpeak NG Korean voice/FFmpeg installed, or dedicated CI. Requires Remotion browser. Real provider acceptance is separate, local only, with explicit cost consent.
