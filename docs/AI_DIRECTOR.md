# AI Director foundation
The optional project creativeBrief captures user purpose, audience, takeaway, tone, mustInclude, avoid. Blank means agent discretion; existing projects remain compatible. Use existing style and original narration, not new timing. In request contextVersion 2 and draftStoryboard, creativeBrief is evidence, not an output field. Remove helper creativeBrief from final board. When configured, direction.plan is required: message, narrative, visualApproach, constraints, referenceDecisions (assetId, reviewed/not_used, notes). Each reference asset must have an honest decision; reviewed is an agent assertion, not automatic inspection. Do not claim reviewed if not opened. Compiler binds current normalized brief to direction.briefKey and preserves explicit user audience. Never set briefKey yourself. Changed brief or missing reference decisions makes old storyboard not ready for production; existing scenes remain as draft, voice remains unchanged. Saved revision and existing review gate still apply. Semantic quality and claims are evaluated by actual agent/human review, not inferred from text fields. No AI API or IDE launch added. Uses shared UI components, no motion effects.
